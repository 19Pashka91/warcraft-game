# Warcraft Java Game

Учебный мини‑проект на Java, демонстрирующий применение ООП (наследование, полиморфизм, абстракция) на примере рас из вселенной Warcraft. 
У каждой расы — уникальные фразы и характеристики, которые выводятся в консоль.

## Расы и персонажи

В проекте реализованы следующие расы с характерными репликами:

- **People (Люди)**: Артас Менетил — *«My blade is ready»*
- **Elves (Эльфы)**: Иллидан Ярость Бури — *«I have done what I must to protect Azeroth»*
- **Orcs (Орки)**: Варок Саурфанг — *«We fight not for glory, but for honor»*
- **Gnomes (Гномы)**: Гелбин Меггакрут — *«Let’s see if this works!»*
- **Undead (Нежить)**: Сильвана Ветрокрылая — *«May death be merciful»*
